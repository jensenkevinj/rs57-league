Salary overrides

Managers trade draft cash. ESPN has no native support for that, so a few player salaries get hand-edited on the two teams involved and changed back before the next draft. An override records the true value while ESPN holds the distorted one.

This is not for fixing a wrong ESPN value
An override is one leg of a draft-cash trade. actual_salary is the true salary and ESPN's figure is the distorted one, for as long as the row is not reverted. Live overrides should net to zero across the league, because a cash trade moves money between two teams — check_override_balance reports it when they do not. If you are here because a number looks wrong rather than because cash changed hands, this is the wrong screen.
